# 🏢 ServiceFlow - Sistema de Gestión de Servicios

**Versión:** 1.0.0  
**Estado:** ✅ Producción

---

## 📋 Descripción

ServiceFlow es una aplicación de escritorio para gestionar servicios, productos, gastos y métricas de negocio.

### Características Principales

✅ Registro de Servicios  
✅ Registro de Productos  
✅ Gestión de Gastos  
✅ Métricas en Tiempo Real  
✅ Historial Completo  
✅ Múltiples Usuarios  
✅ Sincronización Firebase  

---

## 🚀 Instalación

### Opción 1: Descargar Instalador (Recomendado)

1. Descarga: `ServiceFlow Setup 1.0.0.exe`
2. Ejecuta el instalador
3. Sigue los pasos
4. ¡Listo!


### Opción 2: Desde Código Fuente

```bash
# Instalar dependencias
npm install

# Ejecutar
npm start

# Compilar instalador
npm run build
```
